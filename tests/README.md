# OneCopy's areas, and the tests that stand for them

`npm test` runs a fixed list of lanes — the hidden-character and spec-structure checks, the type
check, the frontend bundle, every Vitest test, and every Cargo test — in `scripts/test.mjs`, which
reads nothing about what changed. `npm run test:full` adds the heavy Rust suite, which downloads and
runs the managed tools and models, and on Windows the packaging failure script.

This file is the balance judgement the `tests-folder-conventions` require — which areas OneCopy has,
and which tests stand for each — so a reader can tell what a green run covered, and an area with no
test standing for it is visible rather than merely absent. `tests/area-map.test.ts` holds every path
below to what is on disk.

Paths are relative to the repository root, because OneCopy's tests live in two trees: `tests/` for
the frontend and `src-tauri/tests/` for the core.
